# 🏋️ 운동일지

운동 기록, 유산소 계산, 체중 관리가 가능한 개인 운동 기록 웹앱입니다.

## 🚀 사용하기

웹앱 주소:

https://juwonkim0225-ship-it.github.io/workout-app/

아이폰에서는 Safari에서 접속 후 **홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

---

## ✨ 주요 기능

### 운동 기록

* 운동 종목 기록
* 세트 / 횟수 / 무게 기록
* 운동 부위별 관리

### 유산소 기록

* 러닝머신 속도 입력
* 경사도 입력
* 운동 시간 입력
* 예상 칼로리 계산

### 체중 관리

* 체중 기록
* 목표 체중 설정
* 목표 달성 진행률 표시

### 통계

* PR(최고 기록) 확인
* 총 운동량 확인
* 성장 그래프
* 주간 리포트
* 월간 리포트

### 데이터 관리

* 백업
* 복원
* 전체 초기화
